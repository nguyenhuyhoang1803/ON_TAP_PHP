# BỘ BÀI TẬP TÌM VÀ SỬA LỖI CODE (DEBUG DRILLS)
> **Mục tiêu:** Trong phòng thi, bạn rất dễ gặp các đoạn code bị lỗi hoặc phải sửa code của chính mình khi chạy thử. Bộ bài tập này rèn luyện mắt đọc code, nhận diện 2 – 5 lỗi trí mạng trong 3 – 5 phút.

## Phương Pháp Luyện Tập
1. Đọc lướt đoạn code bị lỗi (Buggy Code).
2. Tự chỉ ra chính xác dòng code bị lỗi và nguy cơ của nó.
3. Viết lại đoạn code đã sửa.
4. Đối chiếu với phần "Phân Tích Lỗi & Code Sửa Chuẩn".
