## Quy Trình Luyện Tập Chuẩn
1. Chuẩn bị đồng hồ bấm giờ (hoặc mở timer trên điện thoại/máy tính).
2. Mở file bài tập, đọc đề trong **30 giây**.
3. Bắt đầu bấm giờ và gõ code trực tiếp trên VS Code.
4. Khi đồng hồ kêu: Dừng tay ngay lập tức, so sánh với `Test Cases` và `Solution`.
5. Đánh giá: Đạt yêu cầu khi **code chạy đúng, không lỗi bảo mật và thời gian $\le$ mốc quy định**.
