# BÀI TẬP RÈN LUYỆN: BẢO MẬT PHÒNG THI

## Đề bài: Thẩm Định & Vá Lỗ Hổng Bảo Mật Dự Án Cũ
Cho một đoạn code quản trị sản phẩm có 5 lỗ hổng bảo mật:
1. XSS ở ô tìm kiếm.
2. SQL Injection ở câu lệnh UPDATE sản phẩm.
3. SQL Injection ở tham số sắp xếp URL.
4. Lộ thông tin cấu trúc CSDL khi trùng tên sản phẩm.
5. Thiếu lệnh `exit` sau khi kiểm tra quyền admin.

Hãy viết lại file quản trị hoàn chỉnh đã vá toàn bộ 5 lỗ hổng trên.
