## Quy Tắc Luyện Tập Nghiêm Ngặt
1. Mở VS Code, tạo một file mới hoàn toàn trống (Ctrl + N).
2. Đọc yêu cầu bài tập.
3. Bấm giờ. **KHÔNG COPY TỪ FILE CŨ, KHÔNG XEM GỢI Ý**.
4. Gõ code liên tục. Tự kiểm tra cú pháp và chạy thử trên trình duyệt hoặc CLI.
5. So sánh với Solution chuẩn sau khi hoàn thành.
